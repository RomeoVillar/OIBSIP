
# Number Guessing Game

**OASIS Infobyte — Java Development**  
**Task 2: Number Guessing Game**

## Project Description
A console-based Java game where the player tries to guess a randomly generated number within a limited number of attempts.

## Features
- Random number generation
- Easy, Medium, and Hard difficulty levels
- User input validation
- Too High, Too Low, and Correct feedback
- Maximum attempts limit
- Play Again option
- Round summaries and final score tracking

## Technologies Used
- Java
- Java Scanner
- Java Random
- IntelliJ IDEA

## How to Run
1. Install a Java Development Kit (JDK).
2. Open NumberGuessingGame.java in IntelliJ IDEA.
3. Run the main() method.
4. Select a difficulty and enter your guesses.
